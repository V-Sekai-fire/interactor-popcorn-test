# interactor-popcorn-test

A minimal Elixir application compiled to WebAssembly with popcorn, to run on AtomVM in a browser.

## What it is for

It is a smoke test for Elixir in the browser: one module that greets and reports what the runtime offers, written within the subset AtomVM supports.

## Build and run

    mix deps.get
    mix build_wasm
